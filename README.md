# 🚀 Projects

## 1. Retail Sales Exploratory Data Analysis

**Level:** L1

Analyzes retail sales data to identify:

* Sales trends
* Customer demographics
* Product performance
* Revenue by category
* Monthly and quarterly trends
* Correlations between numerical variables

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

📂 `DataAnalytics-L1-EDARetailSales/`

---

## 2. Customer Segmentation

**Level:** L1

Segments customers based on purchasing behaviour using **K-Means clustering**.

Key areas include:

* Customer behaviour analysis
* RFM-style features
* Feature scaling
* Elbow Method
* K-Means clustering
* Cluster profiling
* Marketing recommendations

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

📂 `DataAnalytics-L1-CustomerSegmentation/`

---

## 3. Data Cleaning

**Level:** L1

Performs systematic cleaning of a deliberately messy dataset.

The project covers:

* Missing values
* Duplicate records
* Data type correction
* Inconsistent values
* Outlier detection
* Data standardization
* Before-and-after quality comparison

**Technologies:** Python, Pandas, NumPy, Jupyter Notebook

📂 `DataAnalytics-L1-DataCleaning/`

---

## 4. Sentiment Analysis

**Level:** L1

Classifies text data into:

* Positive
* Negative
* Neutral

The project applies NLP preprocessing and machine learning techniques to analyze textual sentiment.

Key techniques include:

* Text preprocessing
* TF-IDF
* Classification
* Confusion matrix
* Model evaluation
* Word clouds

**Technologies:** Python, Pandas, NLTK, Scikit-learn, Matplotlib, Seaborn

📂 `DataAnalytics-L1-SentimentAnalysis/`

---

## 5. House Price Prediction

**Level:** L2

Builds a machine learning model to predict house prices using property-related features.

The project covers:

* Exploratory Data Analysis
* Data preprocessing
* Missing-value handling
* One-Hot Encoding
* Feature selection
* Linear Regression
* Model evaluation
* Actual vs. predicted analysis
* Residual analysis

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

📂 `DataAnalytics-L2-HousePricePrediction/`

---

## 6. Wine Quality Prediction

**Level:** L2

Builds and compares machine learning classification models to predict wine quality based on physicochemical properties.

Models include:

* Random Forest
* SGD Classifier
* Support Vector Classifier

Evaluation includes:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
* Feature Importance

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

📂 `DataAnalytics-L2-WineQualityPrediction/`

---

## 7. Fraud Detection

**Level:** L2

Develops a machine learning pipeline to detect fraudulent financial transactions from a highly imbalanced dataset.

The project focuses on:

* Class imbalance
* Fraud percentage analysis
* SMOTE
* Stratified train-test splitting
* Logistic Regression
* Random Forest
* Precision
* Recall
* F1-score
* ROC-AUC
* Feature importance

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Imbalanced-learn, Matplotlib, Seaborn

📂 `DataAnalytics-L2-FraudDetection/`

---

## 8. Google Play Store Analysis

**Level:** L2

Performs comprehensive analysis of the Google Play Store ecosystem.

The project analyzes:

* App categories
* Ratings
* Installs
* App size
* Free vs. paid applications
* Pricing
* Estimated revenue
* User reviews
* Sentiment by category

An interactive visualization is also developed using **Plotly**.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, TextBlob, Plotly

📂 `DataAnalytics-L2-GooglePlayStoreAnalysis/`

---

## 9. NLP Autocomplete & Autocorrect

**Level:** L2

Analyzes the efficiency and accuracy of autocomplete and autocorrect algorithms using Natural Language Processing.

The project implements:

* Text preprocessing
* Word frequency analysis
* Bigram model
* Trigram model
* Next-word prediction
* Edit-distance-based spelling correction
* PySpellChecker
* Precision and recall
* Confusion matrix
* Algorithm comparison

**Technologies:** Python, Pandas, NLTK, PySpellChecker, Collections, Matplotlib, Seaborn

📂 `DataAnalytics-L2-AutocompleteAutocorrect/`

# ⚙️ Installation

Clone the repository:

```bash
git clone <your-github-repository-url>
```

Navigate to the required project folder:

```bash
cd OIBSIP
```

Each project contains its own `requirements.txt` file.

Install the required dependencies for an individual project:

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Projects

1. Clone this repository.
2. Open the required project folder.
3. Install the dependencies listed in `requirements.txt`.
4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open the project's `.ipynb` file.
6. Run the notebook cells sequentially.
7. Review the generated visualizations, model results, and insights.
