# ⚙️ Installation & Setup

Follow the instructions below to run the projects locally.

## 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

## 2. Navigate to the Repository

```bash
cd Future-AI-Agents-Internship
```

Replace the repository name if your local folder uses a different name.

## 3. Open a Project Folder

For example:

```bash
cd DataAnalytics-L1-EDARetailSales
```

## 4. Install Required Dependencies

Each project contains its own `requirements.txt` file.

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

## 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

## 6. Run the Project

Open the relevant `.ipynb` notebook and execute the cells sequentially.

Review the generated visualizations, machine learning results, and project insights.
